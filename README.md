# Sister Birthday Animated Story & Cinematic Video

A modern, luxury HTML5, CSS3, and JavaScript birthday tribute with cinematic transitions, face-safe photo framing, ambient light backdrops, interactive 3D gift box unboxing, integrated background music, dynamic theme switcher, and celebratory fireworks.

## ✨ Key Features & Improvements
1. **Automatic Background Music**:
   - The provided music track (`assets/audio/birthday_song.mp3`) is pre-loaded and attempts automatic playback on page load.
   - Includes universal first-touch autoplay unlocking and an animated sound wave equalizer in the top bar.
   - Smooth volume fade-in over the first second for a warm, gentle introduction.
2. **Cinematic Transition Effects**:
   - **Golden Light Sweep Wipe**: A radiant beam of starlight and golden prism brilliance sweeps diagonally across the screen during each chapter change.
   - **Vignette Depth Bloom**: An atmospheric camera lens vignette pulse on scene changes.
   - **Camera Dolly Motion**: 3D zoom & depth transitions between scenes.
3. **Responsive Auto-Resize for All Devices**:
   - Built with modern `100dvh` (Dynamic Viewport Height) so it fits mobile browsers without clipping under URL or navigation bars.
   - Fluid typography and adaptive aspect ratios (`clamp()` / `min()`) tailored for 4K desktop screens, tablets, iPhones, Android devices, and landscape phones.
4. **Face-Safe Adaptive Photo Framing**:
   - Custom aspect-ratio frames (`frame-portrait`, `frame-landscape`, `frame-wide`, `frame-tall`) prevent cropping or decapitating any faces.
   - Soft 24px luxury rounded corners, dual-layer ambient backlight reflections, and anchored Ken Burns motion.
   - Interactive Lightbox (🔍) to view any full photo without cropping.
5. **Theme Switcher & Interactive Animations**:
   - 8 dynamic atmospheric themes with background drift (Cosmic Galaxy, Golden Bokeh, Cherry Blossoms, Emerald Aurora, Velvet Roses, Fireworks Night, Glowing Butterflies, Sunset Lanterns).
   - Interactive 3D Gift Box unboxing with secret birthday card reveal.
   - Real-time HTML5 Canvas fireworks and confetti bursts.
   - Synchronized Movie Mode (~14.5s per scene) designed to play alongside the 2-minute 11-second audio track.
